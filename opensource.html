从产品经理日常工作沉淀而来,零构建、一条命令即可部署。支持需求管理、需求润色、迭代管理、甘特视图、模块自定义,并产出 AI 友好的 JSON 成果,便于后续 DevOps 输出给研发。

Built from a product manager's daily work, with zero build steps and one-command deployment. Supports requirements management, requirement polishing, iteration management, a Gantt view, and custom modules — and emits AI-friendly JSON so downstream DevOps can hand off directly to engineering.
