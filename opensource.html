pmtool

Roadmap · FastAPI

PMT 需求管理 Roadmap — 轻量级产品需求管理 / 迭代路线图工具。

PMT — a lightweight product requirements & iteration roadmap tool.

从「智驾采集管理系统」中拆解出的独立 roadmap 模块,零构建、一条命令即可部署。支持需求看板、迭代 / 分类管理、卡片拖拽、多端编辑冲突检测,以及内置 OpenAI 兼容接口的 AI 辅助 PRD 撰写。

An independent roadmap module extracted from a smart-driving collection management system. Zero build steps, deployable with one command. Includes a requirement board, iteration / category management, drag-and-drop cards, multi-editor conflict detection, and AI-assisted PRD writing via an OpenAI-compatible API.
